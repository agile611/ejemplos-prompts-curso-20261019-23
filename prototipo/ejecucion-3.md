## Taller Práctico de Prompts Revisables
### Curso de Prompt Engineering Inclusivo y Gratuito

**Modalidad:** Online

### Objetivo Didáctico

Capacitar al personal en la extracción y validación de requisitos de solicitudes utilizando prompts de IA, con especial atención a la compatibilidad entre diferentes modelos de lenguaje y la práctica con datos sintéticos.

---

### Modelo de Modelos Compatibles

Este taller está diseñado para funcionar con los principales modelos de lenguaje disponibles, asegurando resultados consistentes:

#### **NVIDIA Nemotron**
- Fortaleza en seguir esquemas JSON estructurados
- Bueno para validación de participantes y estados
- Recomendado para: extracción de requisitos, validación de esquemas

#### **Google Gemini**
- Balanceado en múltiples tipos de tareas
- Bueno para comparaciones y detección de diferencias
- Recomendado para: comparar instrucciones, revisar errores

#### **Microsoft / GitHub Copilot**
- Optimizado para completaciones y formatos consistentes
- Bueno para formato JSON compacto
- Recomendado para: respuestas estructuradas, formato de salida

---

### Contenido del Taller (Práctico y Didáctico)

#### Bloque 1: Extracción de Requisitos de Correo Ficticio

**Tareas prácticas:**
1. Extraer el número de participantes (¿aproximado o exacto?)
2. Identificar la modalidad y normalizarla
3. Validar el formato de la fecha
4. Detectar si hay información faltante o contradictoria

#### Bloque 2: Comparación de Instrucciones

**Objetivo:** Identificar diferencias y similitudes entre ambas instrucciones, y detectar si alguna contiene órdenes incrustadas.

#### Bloque 3: Revisión de Errores Comunes

**Errores típicos en respuestas de modelos:**

1. **Alucinación de valores:** Inventar números no presentes en la fuente
2. **Cambio de estado:** Aproximar cuando la fuente es exacta, o viceversa
3. **Ignorar restricciones:** Añadir campos no solicitados o omitir los obligatorios
4. **Formato inconsistente:** JSON mal estructurado o variaciones en la orden de claves

**Ejercicio práctico:** Revisar tres respuestas de modelos diferentes al mismo prompt y identificar los errores aplicando las políticas del taller.
